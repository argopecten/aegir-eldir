# Eldir

Modern admin theme for Aegir Hosting on Drupal 11. Preserves the D7 look and feel with modern CSS architecture, responsive design, and accessibility.

## Requirements

- Drupal 11.0+
- Modern browser (Chrome, Firefox, Safari, Edge)

## Installation

Enable the theme at `/admin/appearance`

## Documentation

- [User Guide](doc/Home.md) - Features, usage, and theme settings
- [Developer Guide](doc/eldir-d11.md) - Technical implementation and API reference
- [D7 Reference](doc/eldir-d7.md) - Original design heritage

## Quick Start

**Theme settings:** `/admin/appearance/settings/eldir`

**CSS variables:** See `css/variables.css` for design tokens

**Components:** Reusable templates in `templates/components/`
