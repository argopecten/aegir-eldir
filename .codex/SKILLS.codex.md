# Eldir Skills Playbook (Codex)

Use these skills for work in this theme repository.

## Skills

- `eldir-create-entity-template`: Add or update entity Twig templates and matching preprocess/CSS wiring.
- `eldir-create-theme-component`: Add reusable custom theme-hook components (hook registration, Twig, preprocess, CSS usage).
- `eldir-add-css-styles`: Place style changes in the correct CSS layer with variables, BEM, and responsive rules.
- `eldir-add-js-behavior`: Add or update Drupal behaviors in `js/eldir.js` using `once()` and safe attach/detach patterns.
